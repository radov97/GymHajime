# GymHajime

GymHajime is a full-stack workout planning and fitness tracking platform that helps users create personalised workout routines, organise exercises by day, track sets and reps, and monitor their training journey.

Built as a learning-focused project with a shared backend API designed to support both web and mobile applications.
